# Математический остров — Главное меню (Python/Pygame)

## 1) Выбор технологии

**Выбрано: Pygame 2.6.1**.

Почему:
- быстро собрать 2D-сцену с мультяшным стилем;
- полный контроль рендера (слои, псевдо-3D, мягкие тени, глянец кнопок);
- простая система анимаций через tween и синусы;
- встроенный звук через `pygame.mixer`;
- легко масштабировать до Scene/UI/Audio архитектуры.

Плюсы:
- низкий порог входа;
- полностью Python;
- хорошо подходит под образовательную игру.

Минусы:
- нет готового high-level UI как в игровых движках;
- часть эффектов рисуется вручную.

Альтернативы:
- **Godot**: сильнее в редакторе сцен, но Python не нативный;
- **Kivy/PyQt**: удобны для приложений, но сложнее добиться игрового «feel»;
- **Panda3D**: избыточно для текущего 2D-экрана.

## 3) «Вырезанные» элементы (текущий подход)

В исходной задаче нужен pixel-perfect re-cut. Поскольку в репозитории не было исходных PNG-слоёв, в текущей итерации использован **процедурный отрисовщик** (vector-style drawing в Pygame).

Что подготовлено вместо вырезания:
- `assets/sounds/*.wav` — синтезированные UI-звуки при первом запуске.
- визуальные элементы рисуются в рантайме в `scenes/menu_scene.py`.

Если нужен строго production-пайплайн вырезки:
1. экспортировать исходное изображение в `assets/reference/menu_reference.png`;
2. нарезать в Figma/Photoshop/Krita по слоям;
3. сохранить PNG в `assets/images/`;
4. заменить procedural-рендер на загрузку готовых спрайтов.

## 4) Анимации

| Что | Тип | Длительность | Easing/формула | Где |
|---|---|---:|---|---|
| Вход лого | Tween translate Y | 0.8s | `ease_out_back` | `MenuScene.title_enter` |
| Вход острова | Tween translate Y | 1.0s | `ease_out_back` | `MenuScene.islands_enter` |
| Вход speech bubble | Tween X справа | 1.1s | `ease_out_back` | `MenuScene.message_enter` |
| Плавание острова | Idle bob | бесконечно | `sin(t*1.2)` | `_draw_island` |
| Плавание робота | Idle bob | бесконечно | `sin(t*2.4)` | `_draw_robot` |
| Движение облаков | Loop drift | бесконечно | линейно + wrap | `_draw_sky` |
| Hover кнопки | scale up/down | ~0.15s | эксп. сглаживание | `GlossyButton.update` |
| Click кнопки | press/release + SFX | event driven | состояние | `GlossyButton.handle_event` |

## 5) Звуки

Синтезируются автоматически скриптом `audio/sound_synth.py`.

| Файл | Назначение | Характер | Длительность |
|---|---|---|---:|
| `hover.wav` | наведение | короткий «пик» | ~0.12s |
| `click.wav` | нажатие | плотный мягкий клик | ~0.18s |
| `error.wav` | ошибка | низкий двойной тон | ~0.25s |
| `menu_open.wav` | открытие меню | rising chime | ~0.22s |
| `whoosh.wav` | вход анимации | свип/вжух | ~0.28s |

Формат: `WAV`, mono, 44.1kHz, 16-bit PCM.

## 6) Архитектура

- `core/scene_manager.py` — переключение/обновление сцен.
- `core/resource_manager.py` — кеш изображений/шрифтов/звуков.
- `scenes/menu_scene.py` — логика и рендер главного меню.
- `ui/button.py` — переиспользуемые глянцевые кнопки.
- `animations/tween.py` — easing и tween-объекты.
- `audio/audio_manager.py` — проигрывание UI SFX.
- `audio/sound_synth.py` — генерация дефолтных звуков.
- `main.py` — bootstrap приложения, loop, event routing.

## 7) Установка среды (для новичка)

1. Установить Python 3.11+.
2. В корне проекта:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install --upgrade pip
   pip install -r requirements.txt
   ```
3. Проверить Pygame:
   ```bash
   python -c "import pygame; print(pygame.version.ver)"
   ```

## 11) Подключение ресурсов

- Кладите свои PNG в `assets/images/`.

- Кладите музыку в `assets/music/`.
- Пути централизованы в `config.py`.

## 12) Запуск

```bash
python main.py
```

Если нет звука в Linux:
- проверьте ALSA/PulseAudio;
- при CI/headless используйте `SDL_AUDIODRIVER=dummy`.
